# 化学モデル対戦 エレメントマスター3D（PWA版）

このフォルダ一式をそのままWebサーバーにアップロードすると、スマートフォンの
ホーム画面に「アプリ」として追加できるようになります（PWA = Progressive Web App）。

## 中身
- `index.html` … ゲーム本体
- `manifest.json` … アプリ名・アイコン・起動時の見た目の設定
- `service-worker.js` … 一度読み込めばオフラインでも遊べるようにするキャッシュ処理
- `icons/` … ホーム画面アイコン一式

## 注意：file:// で直接開くだけでは動きません
`manifest.json` と `service-worker.js` はブラウザのセキュリティ上の理由で、
`http://` または `https://` 経由（＝どこかにホスティングされた状態）でしか機能しません。
ローカルの index.html をダブルクリックして開いた場合、ゲーム自体は遊べますが、
「ホーム画面に追加」してアプリのように使うことはできません。

## 手軽に試す方法（自分のPC上で）
このフォルダの中で以下を実行し、
```
python3 -m http.server 8080
```
スマホとPCを同じWi-Fiに繋いだ状態で、スマホのブラウザから
`http://（PCのIPアドレス）:8080/` にアクセスしてください。

## 実際に公開する方法（おすすめ・無料）
以下のような静的ホスティングサービスに、このフォルダをそのままアップロードするだけで公開できます。
- Netlify（サイトの管理画面にフォルダをドラッグ＆ドロップするだけ）
- Vercel
- GitHub Pages
- Cloudflare Pages

## ホーム画面への追加方法
公開したURLにスマホのブラウザでアクセスした後、

**iPhone（Safari）:**
共有ボタン → 「ホーム画面に追加」

**Android（Chrome）:**
右上のメニュー（縦三点）→ 「アプリをインストール」または「ホーム画面に追加」

これで、ホーム画面のアイコンをタップするとブラウザのアドレスバーなどが表示されない
全画面のアプリのような見た目で起動します。

## 今後さらに「本物のアプリ」に近づけたい場合
App Store / Google Playに正式に公開したい場合は、このPWAをベースに
Capacitor（https://capacitorjs.com/）などのツールで実機ビルド・署名・ストア申請を行う
次のステップが必要です。これはXcode/Android StudioやApple/Googleの開発者アカウントが
必要な作業のため、この環境の中だけでは完結できません。まずは上記の方法でPWAとして
配布・体験してみて、必要であれば次のステップとして検討してください。
