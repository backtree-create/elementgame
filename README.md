# 化学モデル対戦 エレメントマスター3D（PWA版）

このフォルダの中身をそのままGitHubリポジトリにアップロードすると、
スマートフォン・タブレットのホーム画面に「アプリ」として追加できるようになります。

## 中身（全部で8ファイル、フォルダなし）
- `index.html` … ゲーム本体
- `manifest.json` … アプリ名・アイコン・起動時の見た目の設定
- `service-worker.js` … オフラインでも遊べるようにするキャッシュ処理
- `icon-192.png` / `icon-512.png` / `icon-512-maskable.png` / `apple-touch-icon.png` / `favicon-32.png` … アイコン画像一式

## これまでの修正内容
1. アイコン画像の四隅を透過にしていたのを、OS側の角丸マスクを前提とした
   透過なしのフル正方形画像に修正（iOS/Android共通の作法に合わせた）
2. `icons` フォルダをやめ、すべてのファイルをフォルダなしで同じ階層に配置
   （GitHubのアップロード時にフォルダが認識されない問題を回避）
3. **【今回の修正・最重要】`service-worker.js` のインストール失敗を修正**
   外部CDN（Three.js）のURLを、ゲーム本体のファイルと一緒に
   `cache.addAll()`（1つでも失敗したら全部失敗する処理）に含めてしまっていました。
   これによりService Worker自体のインストールが丸ごと失敗し、
   ブラウザから見て「正式にインストール可能なPWA」と認識されず、
   指定したアイコンではなく汎用アイコンが使われる状態になっていました。
   これが「ファイルを直しても反映されない」の実質的な原因です。
   外部CDNは事前キャッシュの対象から外し、実際に読み込まれたタイミングで
   自動的にキャッシュする方式に変更しました。

## GitHubへのアップロード方法
1. リポジトリのページで「Add file」→「Upload files」をクリック
2. このフォルダの中の8ファイルすべてを一度に選択し、画面にドラッグ＆ドロップ
   （またはクリックしてファイル選択ダイアログから8つとも選ぶ）
3. 下部の「Commit changes」を押せば完了（同名ファイルは自動的に上書きされます）

## 既にホーム画面に追加していた場合の注意（重要）
GitHub上のファイルを更新しても、スマホ・タブレット側にキャッシュされた
古いアイコン／service-workerが残っていると反映されないことがあります。
更新後は以下の順番で確認してください。

1. 既にホーム画面に追加してあるアイコンがあれば、一度削除する
2. Safari／Chromeでサイトを開き直す（シークレット/プライベートタブで開くと確実）
3. 新しいアイコンが表示されているのを確認してから、改めて「ホーム画面に追加」する

## 注意：file:// で直接開くだけでは動きません
`manifest.json` と `service-worker.js` は `http://` または `https://` 経由
（＝どこかにホスティングされた状態）でしか機能しません。
ローカルで index.html を直接開いた場合、ゲーム自体は遊べますが
「ホーム画面に追加」してアプリのように使うことはできません。

## ホーム画面への追加方法
**iPhone / iPad（Safari）:**
共有ボタン → 「ホーム画面に追加」

**Android（Chrome）:**
右上のメニュー（縦三点）→ 「アプリをインストール」または「ホーム画面に追加」
