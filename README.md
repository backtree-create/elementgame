# 化学モデル対戦 エレメントマスター3D（PWA版）

このフォルダ一式をそのままWebサーバーにアップロードすると、スマートフォン・タブレットの
ホーム画面に「アプリ」として追加できるようになります（PWA = Progressive Web App）。

## 中身
- `index.html` … ゲーム本体
- `manifest.json` … アプリ名・アイコン・起動時の見た目の設定
- `service-worker.js` … 一度読み込めばオフラインでも遊べるようにするキャッシュ処理
- `icons/` … ホーム画面アイコン一式

## 今回のアイコン不具合の修正について
以前のバージョンではアイコン画像の四隅を透過にしていましたが、iOS/Androidは
「四隅まで塗りつぶされた正方形」のアイコンを前提に、OS側で自動的に角丸マスクを
かける仕組みになっています。透過だとOSによって角が黒く欠けたり、
ホーム画面に反映されないことがあったため、すべてのアイコンを透過なしの
フルサイズ正方形画像に作り直しました。

## 既にホーム画面に追加していた場合の注意（重要）
GitHub上のファイルを新しいものに差し替えても、
- スマホ・タブレットのブラウザ／OSがアイコン画像やservice-workerを
  キャッシュしている
- 一度ホーム画面に追加したアイコンは、追加した時点の画像のまま固定される
  （サーバー側の更新が自動反映されない）

という理由で、**古いアイコンのままになることがあります**。
更新後は以下の手順を行ってください。

1. 既にホーム画面に追加してあるアイコンがあれば、一度削除する
2. Safari／Chromeでこのサイトを開き直す（できればキャッシュを一度削除するか、
   プライベート/シークレットタブで開いて確認する）
3. 新しいアイコンが表示された状態を確認してから、改めて「ホーム画面に追加」する

## 注意：file:// で直接開くだけでは動きません
`manifest.json` と `service-worker.js` はブラウザのセキュリティ上の理由で、
`http://` または `https://` 経由（＝どこかにホスティングされた状態）でしか機能しません。

## GitHub Pagesへのアップロード方法
1. GitHubのリポジトリページで「Add file」→「Upload files」
2. このフォルダの中身（index.html・manifest.json・service-worker.js・icons フォルダ）を
   まとめてドラッグ＆ドロップ（既存ファイルは自動的に上書きされます）
3. 「Commit changes」で確定
4. 1〜2分待って公開ページを再読み込み

## ホーム画面への追加方法
**iPhone / iPad（Safari）:**
共有ボタン → 「ホーム画面に追加」

**Android（Chrome）:**
右上のメニュー（縦三点）→ 「アプリをインストール」または「ホーム画面に追加」
